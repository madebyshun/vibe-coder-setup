# Landing Page

## Step 1 — Ask (only what's missing from CLAUDE.md)
- What is the product, in one sentence?
- Who is it for?
- What is the ONE action visitors should take? (sign up / try it / join waitlist / buy)

## Step 2 — Plan (show this, wait for OK)
Propose sections, one line each. Default structure:
1. Hero — headline (benefit, ≤ 8 words), subline, one CTA, product visual
2. Proof — logos, numbers, or one testimonial
3. How it works — 3 steps
4. Features — 3 to 6, each with a one-line benefit
5. FAQ — 4 to 6 real objections
6. Final CTA — repeat the main action

Write the actual headline and CTA copy in the plan so the user can react to words, not placeholders.

## Step 3 — Build
- Follow CLAUDE.md brand + design rules.
- Mobile-first, then desktop.
- Semantic HTML, alt text, meta title + description, Open Graph image tag.
- Run it and check it in the browser at 375px and 1440px before saying it's done.

## Step 4 — Hand off
Tell the user: what was built, how to run it, and 2–3 things worth testing with real users.
